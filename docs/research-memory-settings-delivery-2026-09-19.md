## 3. 使用步骤

### 3.1 启动更新后的网页

停止原 Web Python 进程后，在现有环境启动；不需要重新登录 NapCat：

```powershell
conda activate agent
cd E:\Agent\travel_agent
python run_web.py
```

前端已在本机重新构建。以后代码重新拉取且没有构建产物时，需要在 `frontend` 执行 `npm ci`、`npm run build`，再启动后端。保持同一数据目录只运行一个后台服务。

### 3.2 只增加搜索配置，保留原高德和 LLM

1. 打开左下角“状态与设置”，找到“服务配置”。
2. 在 `Tavily 搜索 Key` 输入你自己的 Key。
3. 搜索地址显示 `https://api.tavily.com`，首版固定使用该供应商地址，无需另填。
4. 高德、模型 Key 输入框保持空白，不点“清除”。原值会保留。
5. 点击“保存服务配置”。成功后输入框清空，只显示“已配置”。
6. 可点击“测试已保存搜索配置”，后端向 Tavily 发起一条固定的“武汉 官方 旅游”查询。
7. 重启 Web 后端。保存后的测试使用新文件值；聊天运行时在重启前仍使用启动时配置。

搜索服务接口依据已核对的 [Tavily Search 文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)，采用 Bearer 认证和 `/search`。这不代表已替用户注册账号、购买套餐或验证其搜索 Key。

“已配置”仅表示存在配置；额度、模型能力和服务可用性以实际请求为准。模型 `/models` 不支持时，连接测试可能失败，但不能仅凭这一点断言模型推理接口不可用。

### 3.3 攻略研究

```text
帮我搜索武汉三日游攻略
帮我查西安近期攻略
读取公开页面 https://www.hbww.org.cn/fuwu/index.html
查看研究进度
查看研究结果
根据研究结果规划武汉三天行程
```

泛化的“帮我查攻略”会追问目的地；同一成员的短回复可以接续。明确的“搜索并规划……行程”可在已有授权下继续生成新行程草案。涉及原有行程和关联提醒时，继续走既有预览与版本校验。

没有搜索 Key 时，指定公开页面阅读仍可使用；普通搜索会明确提示未配置。某页面不可读时保留“仅搜索摘要”或“读取失败”，不声称已读全文。超过七天的研究报告不直接拿来生成新行程，需要重新研究；预约规则仍由原预约服务重新读取，不用研究报告代替生效规则。

研究侧栏显示阶段和来源数，详细引用在聊天回复中。“填入基于研究结果的规划请求”只填入草稿，不擅自提交；可再补城市和天数。

### 3.4 保存和使用偏好

```text
记住，以后优先公共交通，轻松节奏
我一般喜欢博物馆
保存偏好建议
查看我的偏好
忘记我的交通偏好
忘记所有偏好
暂停应用偏好
启用偏好
关闭偏好建议
```

也可在“我的偏好”面板选择、编辑。预算必须有金额、币种、每人/总额、每天/全程和适用项目；不完整金额不会自动成为预算限制。面板支持忘记所有偏好，聊天回执和已经保存的行程不会因此被删除。

新建 Web 会话后，规划器会把适用的节奏、交通、夜游、兴趣和预算作为默认条件，并在行程里说明采用了哪些偏好；明确的本次要求优先。常用出发城市作为上下文候选，不当成当前位置，也不自动改变目的地。回复风格用于模型回答上下文，不改业务回执中必须展示的信息。

“本次不用偏好”可以关闭该请求的偏好输入。当前网页是 `local-owner` 单使用者，没有账号注册或多账号认证；同一电脑访问同一个本地服务的人不能据此视为彼此隔离。

## 4. 密钥保护措施

- GET、保存回执、异常响应不返回原始 Key；配置端点自行验证请求，避免 Pydantic 默认 `input` 把错误值回传。
- 独立配置表单不使用聊天草稿机制，密钥不进入 localStorage/sessionStorage、SQLite 偏好或模型上下文。
- 字段白名单、控制字符/插值语法拒绝、dotenv 引号转义与解析往返校验；重复键或无法可靠解析的文件拒绝写入。
- 固定 `.env` 路径，跨进程锁、版本冲突检查、同目录临时文件、受限权限及原子替换；失败保留旧文件并清理本次临时文件。
- Windows 使用 NTFS ACL，仅允许当前运行身份；POSIX 使用 `0600`。不通过降低文件权限来绕过失败，不默认生成含密钥备份。
- 启动环境控制的字段只读；清除项目凭据通过空值抑制父目录回退，避免清除后又悄悄启用父目录旧值。
- 更换模型地址须重新输入用于该地址的 Key；连接测试不接受任意测试 URL，认证请求不跟随重定向。
- 新增公网 HTTPS 传输：先解析并校验地址，连接到验证过的 IP，同时按原域名验证 TLS，防止校验后再次解析落入内网；不关闭证书校验。
- `.gitignore` 覆盖 `.env.*`、临时配置与轮转日志，只放行示例模板；`.dockerignore` 限制构建上下文。
- 保存前检测 Git 跟踪与忽略状态；已跟踪 `.env` 时拒绝保存新凭据。新增暂存区和推送检查，匹配结果只显示路径和规则。

本地 hook 已配置为 `.githooks`。换电脑或重新克隆后需安装：

```powershell
git config --local core.hooksPath .githooks
python scripts/check_secrets.py --all-tracked
```

Linux 上还需使 hook 文件可执行。提交/推送应从能执行项目 Python 依赖的环境进行。CI 已增加检查步骤，但本次未推送，未执行远端 CI。

`.env` 仍为本机明文文件。Git 忽略不覆盖强制 add、手工 ZIP 上传、旧提交、恶意本机软件或远端副本；hook 可被绕过，CI 也发生在推送之后。若真实密钥曾公开，需先轮换。内置扫描识别常见格式及本地已知 Key，不是覆盖所有编码、分片或历史泄漏的专业审计。

## 6. 实施取舍与当前边界

1. 搜索首版采用一个 Tavily 适配器及固定官方端点，没有同时接多家或做未持有凭据的真实质量对比。自定义任意搜索 URL 尚不支持。
2. 首版每任务一次搜索、最多顺序读取五个页面；上限比方案中的“最多三次搜索、并发二”更保守，已提供可恢复检查点，不做无边界探索。
3. 偏好和研究的明确入口先使用可验证的轻量规则接入现有应用，避免给每条消息新增一轮意图模型调用；没有把现有 Intent IR 全部重写。新账号/身份字段已加入模型禁止生成清单。
4. 偏好自然语言支持常用明确表达和候选确认，尚不是任意措辞的自动画像。否定、不明确、单次或涉及他人的表达不自动写入。复杂预算请使用面板。
5. 网页正文首版按 UTF-8 读取，纯 HTML/文本优先；动态渲染、特殊编码、登录墙可能不可读。发布时间缺失明确标未知。模型能引用来源不代表每项事实已经逐条独立验证。
6. 高德连接测试不放进配置面板，避免在通用测试链路中使用带 Key 的查询 URL；重启后可用天气请求验证。既有高德业务协议未改写。
7. 保存后需要重启，不提供对在途任务的热切换。Docker 容器写配置与远程多账号模式本轮未验收，保持本机单使用者范围。
8. 本轮未构建向量库、跨会话文件知识库、自动安装 skill、购票或支付。原方案的 skill 候选设计保留后续评测后实施。
