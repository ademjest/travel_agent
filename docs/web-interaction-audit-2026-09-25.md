# Web 交互界面与模块合理性审查

日期：2026-09-25  
范围：`frontend/src`、Web API、提醒调度与通知生命周期  
依据：当前代码、桌面截图、前后端自动化测试

## 1. 结论

当前 Web 端的三栏主体结构合理：左侧负责全局导航和本地功能入口，中间负责对话，右侧负责当前旅行的结构化结果。主要问题不在总体布局，而在局部模块职责重叠、服务配置字段缺少显式控件 Schema、通知缺少即时反馈，以及 `App.tsx` 承担过多状态和流程。

本轮已修复影响用户直接操作的问题；较大的组件拆分和产品结构调整保留为后续重构，不在本轮扩大改动范围。

## 3. 本轮已修复的问题

### 3.1 配置字段控件

原实现通过字段名包含 `PRICE` 来判断数字输入，导致 `LLM_PRICE_CURRENCY` 被错误渲染为数字框；所有其他字段又共用“服务地址或模型名称”占位提示。

现改为显式字段控件 Schema，每项分别定义：

- `text`、`password`、`url` 或 `number`；
- `inputMode`；
- 小数步长或 token 步长；
- 最小值和最大长度；
- 字段专属占位提示；
- 用途说明与示例。

费率币种现在是三位文本输入，会自动转为大写，可输入 `CNY`、`USD`、`EUR` 等代码。费率数字支持 `0.001` 步长，不再默认按整数增减。

### 3.2 服务配置的信息层级

配置划分为：

1. 联网搜索；
2. 模型与地图基础配置；
3. 用途模型；
4. 预算与记忆；
5. 费用估算。

前两组默认展开；后三组属于高级设置，默认折叠。未做任何修改时“保存服务配置”不可点击。

### 3.3 左侧模块职责

原“状态与设置”同时承载后台状态、服务配置、模型用量和偏好，职责过多。现在拆为三个入口：

- 本地空间状态：本地数据隔离、排队任务和后台进程；
- 服务配置：外部服务、模型、预算、用量；
- 偏好设置：长期旅行默认。

### 3.4 通知与提醒

- 新通知在页面内显示可点击提示；
- 初次打开页面时，未读且未过期的通知也会提示；
- 超过 24 小时补发窗口的个人提醒自动删除；
- 提醒通知保留 24 小时，其他旅途通知保留 7 天；
- 兼容无法关联 Outbox 的旧提醒文本；
- 页面关闭期间仍写入站内通知，但不提供操作系统级推送。

### 3.5 可访问性与窄屏

- 字段说明通过 `aria-describedby` 关联输入控件；
- 模型用量表增加横向滚动容器；
- 配置分组在窄屏切换为单列；
- 通知提示使用 `role=status` 和 `aria-live=polite`；
- 左侧入口保持移动端最小 44px 点击高度。

## 4. 当前仍建议后续改进

### P1：拆分 `App.tsx`

`App.tsx` 同时管理会话、轮询、通知、上传、确认、删除、左右面板和多个弹窗。建议后续逐步拆为：

- `useConversationSession`；
- `useNotifications`；
- `useDeletionJobs`；
- `ConversationSidebar`；
- `TravelDetailsPanel`；
- `NotificationCenter`；
- `ConfirmationCard`。

这属于可维护性改造，应保持行为不变并分批实施。

### P1：统一配置 Schema 来源

目前后端维护字段白名单和校验，前端维护控件类型、帮助和示例。虽然本轮已改为显式 Schema，但两端仍可能随新增字段发生漂移。建议后端设置接口未来返回非敏感 UI 元数据，前端只负责渲染。

### P1：替换原生 `window.confirm`

删除规划方案仍使用 `window.confirm`，与现有会话删除对话框风格和可访问性不一致。建议统一为应用内确认对话框。

### P1：研究面板错误反馈

`ResearchPanel` 当前静默忽略轮询错误。建议显示“暂时无法同步研究状态”，并允许手动重试，避免用户误以为没有启动研究。

### P2：右侧研究信息的位置

研究状态目前始终显示在右侧标签上方，即使用户正在查看提醒或资料。后续可考虑并入“方案”标签或增加“研究”标签，减少跨模块视觉干扰。

### P2：本地空间容量

当前本地空间状态显示数据隔离、队列和后台进程，但不显示数据库及附件占用空间。若后续增加清理工具，可在此处补充只读容量信息；不建议仅为展示容量引入新的扫描开销。

### P2：系统级通知

当前实现是网页内提示和站内通知，不是浏览器 Notification API 或操作系统推送。若未来需要后台系统通知，必须增加用户授权、权限状态、隐私说明和失败回退，不能默认开启。
