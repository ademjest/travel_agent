先说明一个关键点：开启摘要后，不会每轮都生成摘要。 当前首次触发通常要求同时满足：
- 已保存至少 8 轮对话。
- 这些对话的用户输入＋助手回复累计至少 9000 字符，不是 9000 Token。
- 当前请求进入需要摘要的上下文路径。普通讨论适合测试；纯天气、路线等快速查询可能跳过摘要生成。

4. 想确认“真的生成了摘要”，可以只读查看数据库。

   import sqlite3
   from pathlib import Path
   
   path = Path(r"E:\Agent\travel_agent\data\web\travel_bot.db")
   db = sqlite3.connect(path.as_uri() + "?mode=ro")
   db.row_factory = sqlite3.Row

       SELECT group_openid, member_openid
       FROM conversation_turns
       WHERE user_content LIKE '%摘要实验A%'
       ORDER BY id DESC LIMIT 1

   print("本会话累计：", dict(row))

              summary, items_json
       FROM conversation_summaries

   if summary is None:
       print("尚无摘要记录。")
   else:
       for key in summary.keys():

   如果“模型用量里有摘要调用，但没有有效摘要”，可能是输出校验失败、预算问题或发布时依赖变化，不能直接归因于记忆能力差。
5. 这样解读结果，才能判断问题出在哪一层。
   观察结果	更可能说明什么
   没有摘要调用	开关未生效、没到阈值，或请求没有进入摘要路径
   有调用，但没有成功保存摘要	生成、校验或发布环节失败
   摘要保存成功，但缺少关键事实	摘要选择或压缩质量不足
   摘要保留了事实，最终回答仍错误	需要继续检查上下文注入和模型使用
   回忆正确，但评价活动时没指出冲突	事实保留成功，约束应用失败
   全部正确	本用例通过；还不能代表所有长对话都可靠
