## 交付结果

已新增可独立启动的本地网页入口，默认地址 `http://127.0.0.1:8080`。后端复用原有 Agent、旅行工具、任务队列、租约、提醒调度与业务服务。无需 QQ 在线或配置 QQ 凭据。保留原 QQ 入口；Web 数据默认独立保存于 `data/web/`，本轮没有迁移 QQ 资料或发送真实 QQ 消息。

本地服务已在实施过程中启动并通过 `/health/ready` 检查。服务是否仍在运行取决于后续电脑和进程状态；停止后可使用 `python run_web.py` 或 `start-web.cmd` 再次启动。

## 已实现

- React／TypeScript／Vite 界面，暖白与深青绿配色；会话列表、对话区、可折叠旅行侧栏及移动端抽屉。
- 文本对话、自然语言澄清、Markdown 和长表格显示、复制回复、草稿、历史分页、重命名会话。
- 图片和文档上传、预览与受控本地附件接入，复用原文档与图片处理服务。
- 结构化行程、普通提醒、图片预约计划、定时查询、规则监测及站内通知。
- 已有任务式确认生成版本绑定卡片；尚未结构化的图片预约确认仍沿用明确的聊天命令，不渲染假确认按钮。
- 请求持久化、幂等提交、后台进度、取消、租约恢复和输出去重；网页断线不取消后台任务。
- 稳定本地使用者、会话 Cookie、CSRF、Host／Origin 校验、附件归属与文件内容校验。
- 独立数据目录、单目录单后台实例锁、端口和浏览器启动配置、健康检查。
- 单地址静态发布模式、本地启动脚本、依赖锁、前端 CI 检查及使用文档。

为保持改动范围，内部仍使用现有 group 通道承载 Web 会话范围，但平台明确为 web，不伪造 QQ ID 或 OneBot 报文。QQ 的触发、私聊绑定和投递继续由原适配器处理。

样式实现使用一个应用级 CSS 文件和设计变量；没有为本轮单页面额外建立 CSS Modules 分层。前端交互单元测试采用 Vitest／Testing Library，浏览器检查通过当前工具的 Playwright 接口和页面操作完成，没有加入尚未运行的独立 Playwright 测试命令。

## 验收限制与保留边界

1. 内嵌浏览器的自动化文件选择 API 两次超时，未完成原生文件选择窗口的端到端验收。React 文件选择事件、multipart 上传、附件验证、实际文档导入均已分别通过测试。这是浏览器自动化的已知验收限制，不将其声称为完整原生上传交互通过。
2. 内嵌浏览器未响应缩放快捷键，未能确认实际达到 200% 缩放。已完成四档视口尺寸检查，但不将它们等同于独立的 200% 缩放验收。
3. 图片输入已验证受控本地附件到原图片服务的接入；本轮真实接口脚本没有额外执行多模态图片识别。预约图片原业务由既有回归测试覆盖。
4. 未进行 Docker 构建、Linux 实机或远程多人访问验收。CI 配置包含后续 Windows／Linux Python 检查及 Linux 前端构建，不代表本轮已运行远端 CI。
5. 单使用者本地模式不隔离同一电脑上的其他使用者。QQ 与网页历史仍不自动互通；浏览器关闭后需保持后台运行才会继续提醒。
6. 模型及数据源本身仍有不确定性：真实行程中无法核实的交通段继续明确标注，换成网页不会扩大现有业务保证。

## 与 Docker 相关的改动

没有新增 Dockerfile、Compose 或构建镜像。由于将通用 Python 依赖提取到 `requirements-core.txt`，仅在原 NapCat Dockerfile 的依赖复制清单增加该文件，避免原 QQ 部署入口因依赖拆分失效；未对其做容器构建验收。

已预留可配置端口、数据目录、静态构建产物、标准日志及不打开浏览器的启动选项，后续可以在这些边界上实现容器部署。

## 后续修复：提醒时间口语接续

同日使用中发现：“明天提醒我预约陕西历史博物馆”之后回复“10点吧”，末尾语气词未被时间回答识别规则接受，消息落入普通聊天，模型误称缺少提醒工具。已修复 `is_time_answer` 对末尾“吧／呀／啊／呢”及标点的识别；仍拒绝否定语句、多个备选时间及其他意图，不因此默认猜测上午或晚上。

新增回归覆盖“提醒事项 → 10点吧 → 上午吧”并验证只有一条正确提醒，以及网页不会调用普通聊天兜底。修复前测试复现失败，修复后个人提醒 10 项、Web 21 项、定时查询 14 项、规则监测 9 项，共 54 项相关测试通过。未改写正式数据或自动补建用户的提醒。

该字符匹配修补随后升级为[上下文 LLM 提醒接续](semantic-reminder-continuation-2026-09-18.md)：移除自然语言关键词门槛，向模型提供实际待完成任务，以结构化字段直接调用业务服务。完整回归 560 项通过，并完成真实模型多轮、无触发关键词新建和取消设置联调。先前的时间规则只保留为时间校验与有限回退，不作为提醒语义的主要入口。
