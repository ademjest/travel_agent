# 一键测试全部服务：交付说明

日期：2026-10-15

## 功能

服务配置区新增“一键测试全部服务”。它使用服务器上的已保存配置，不接受浏览器提交任意 URL 或密钥进行探测。存在未保存修改时先保存再测试。

| 对象 | 测试方式 | 通过的含义 |
| --- | --- | --- |
| 默认、意图、摘要、研究模型 | 固定的最小 Chat Completions 请求 | 指定模型能完成文本推理请求 |
| 视觉模型（未单独配置时沿用默认模型） | 固定 16×16 PNG 和简短文本 | 指定模型接受图片输入并返回文本 |
| Tavily | 一次固定旅游搜索 | 搜索接口认证和响应正常，允许结果为空 |
| 高德 | 固定北京行政区的一次天气请求 | 当前 Key 可使用天气接口，并返回有效结果 |

相同文本模型只测试一次，显示合并的用途名称。视觉输入单独测试；不能以文本成功替代图片能力验证。未配置完整的对象标记为跳过；某个请求失败不会中断其余项目。

测试是实际服务请求，可能消耗少量费用或额度。请求不包含用户聊天、文档或附件；图片为代码内固定测试图。成功仅代表表格所述能力，不自动证明工具调用、JSON 输出、复杂图像理解或所有高德接口权限可用。

## 界面

- 蓝紫色浮层，与原 Web 的绿色配置界面区分。
- 显示通过/失败/跳过汇总，以及每项模型名称、状态、说明和耗时。
- 请求进行中显示等待提示；测试结束后开始 20 秒自动关闭计时。
- 鼠标悬停或键盘聚焦时暂停自动关闭，离开后重新计时。
- 右上角 × 可随时关闭。进行中关闭只隐藏浮层，完成后不会自行重新弹出。
- 配置已保存但尚未重启时，提示本次测试新配置，当前 Agent 仍需重启。
- 整体请求失败时也在浮层显示错误，可手动关闭或等待自动关闭。

## 后端与用量

- 复用带会话与 CSRF 校验的 `POST /api/settings/services/test`，增加 `service=all`。
- 仅使用服务端保存的配置；不接受外部指定的测试地址。
- 最多 3 个测试任务并行；模型推理仍经过现有模型网关的并发和预算控制。
- LLM/Tavily 网络请求沿用公网 HTTPS 校验，模型请求超时 20 秒、返回体限制 100 KB；高德沿用客户端 10 秒超时。
- 同一实例已有测试时拒绝重复启动，返回 409。前端也禁用重复点击。
- 错误转换为固定说明，不返回原始供应商异常正文、密钥或带密钥的高德请求 URL。
- 模型测试使用 `service_probe` 用途进入现有 token 和费用统计；不同用途模型没有费率时不套用默认模型的价格。

## 改动文件

- `infrastructure/service_probes.py`：固定探测、模型去重、并发和错误脱敏。
- `infrastructure/env_settings_store.py`：读取已保存配置并防止测试重入。
- `infrastructure/model_gateway.py`：支持探测时明确默认模型，保证不同模型的费率边界。
- `adapters/web_app.py`：一键测试 API 分发与重复请求提示。
- `frontend/src/SettingsPanel.tsx`、`frontend/src/styles.css`：按钮、浮层、状态和关闭交互。
- `tests/test_service_settings.py`、`frontend/src/SettingsPanel.test.tsx`：后端与界面测试。

## 测试与验收

自动化测试仅使用固定凭据、模拟服务响应和临时数据库，没有使用正式 Key 发出收费请求。

已覆盖：默认和各用途模型选择、同名去重、视觉请求、搜索/高德成功、未配置跳过、失败隔离、密钥不回显、CSRF、重复请求拦截、token 记录、用途模型未知费率、未保存时禁用、结果显示、错误提示、20 秒关闭、悬停和聚焦暂停、测试过程中关闭后不重开。

最终结果：

- 后端全量：852 项全部通过，约 464 秒（Python 3.11.15 / Conda agent）；测试期间源文件保持一致。
- 服务配置专项：21 项通过；模型网关专项：11 项通过。
- 前端全量：41 项通过；TypeScript 与生产构建通过，构建产物已更新。
- Python 编译检查和 `git diff --check` 通过。
- 证据：`evals/service-connectivity-tests-backend-2026-10-15.json`、`evals/service-connectivity-tests-frontend-2026-10-15.json`。

人工验收：

1. 重启后端并刷新服务配置页面。
2. 保存完整的模型、Tavily 和高德配置；点击“一键测试全部服务”。
3. 检查蓝紫色浮层中结果、模型名称和耗时。
4. 临时用无效测试 Key 检查失败项，确认其余项目仍有结果；验收后恢复正确 Key。
5. 测试手动关闭、完成后 20 秒关闭、悬停/聚焦暂停。
6. 查看模型用量中的 `service_probe` 分类。

本轮不启动 `run_web.py`，不遗留 Web 测试进程。
