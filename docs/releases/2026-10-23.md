# 2026-10-23 数据来源与可靠性更新

本分支同步本地最新业务代码。初次使用见 [Web 指南](../guides/web.md) 或 [QQ 指南](../guides/qq.md)，此前功能见 [2026-10-19 更新记录](2026-10-19.md)。

## 功能变化

- 新增可选携程问道资料来源：在“服务配置”中填写 `WENDAO_API_KEY` 并启用 `WENDAO_ENABLED`，保存后重启；默认关闭。供应商综合回答与官方核验分开展示，失败不会自动重新提交。
- 旅行回答结合已保存行程与研究资料组织内容，保留来源、不确定信息和核验状态；资料不足时不将参考内容当作已确认事实。
- 改进景点名称关联、规则语义判断及后续问答的资料接续，按景点展示研究结果与待确认事项。
- Web 右侧面板支持拖动调整宽度，并改进行程、研究和服务配置展示。
- 统一 Web、QQ 与回归验证日志位置，默认保存到项目同级 `travel_agent_val_log` 目录。

## 升级方式

1. 停止后端，备份自己的 `.env` 与数据目录；Web 默认数据目录为 `data/web`。
2. 更新源码，执行 `python -m pip install -r requirements-web.txt -c constraints-py311.txt`；QQ 用户按对应指南安装入口依赖。
3. 在 `frontend` 执行 `npm ci`、`npm run build`，再从项目根目录运行 `python run_web.py`。
4. 保留已有配置，不用模板覆盖 `.env`；新增问道来源按需启用，需要有效凭据与供应商额度。

`docs/` 仅提供使用指南与发布记录。运行必需的摘要提示词位于 `prompts/conversation_summary.md`；公开景点别名位于 `data/attraction_aliases.json`，随源码分发。数据库、真实密钥、运行日志和本地研究方案不随本分支发布。
