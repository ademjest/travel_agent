# 2026-10-19 项目同步与部署说明

本次将本地持续迭代的 Web、Agent 核心、QQ 接入、测试与使用文档同步为同一份源码版本。日常操作从 [Web 指南](../guides/web.md) 或 [QQ 指南](../guides/qq.md) 开始，项目概览见 [README](../../README.md)。

## 主要更新

- Web 可以独立于 QQ 使用，支持多会话、附件、版本绑定的行程预览、任务取消及会话关联资源清理。
- 语义意图与服务端校验对接持久化任务，支持自然表达的提醒、复杂出行查询、方案接续与增量旅行要求。
- 国内攻略按选源 skill 优先中文社区和旅游平台；景点票价、开放、预约规则采用有上限的分批研究与正文引文核验。支持关联已有方案，区分抵达日期和游览日期。
- 方案捕获排除普通能力介绍和演示行程，修复局部“一日游”被误记为总天数；旧活动草稿按版本重新校验。
- 景点日序根据原方案结构核对，模型日序提示错误时可以纠正；无法确定时显示“游览日待确认”，继续查询，避免将一处日序问题扩大为整次研究失败。
- 酒店和餐饮候选结合品牌、评分、预算及行程位置筛选，显示供应商实际提供的参考价格。酒店参考均价不等于特定日期的房型报价或可订房量；缺失数据不推算为已知价格。
- 新增按需会话摘要、可选本地语义检索、用途模型与预算控制、实际费率估算、按会话 token 统计和消息处理诊断。
- Web 服务配置支持更换基础参数和测试模型、Tavily、高德服务；回复支持 Markdown 和 LaTeX 公式。

## 新用户部署

推荐使用 Python 3.11、Node.js 24，通过 README 中 Windows 或 Linux/macOS 命令安装。

1. 克隆仓库，安装 `requirements-web.txt`，同时应用 `constraints-py311.txt`。
2. 将 `.env.example` 复制为 `.env`，或启动后通过“服务配置”填写模型、高德与 Tavily 参数。
3. 在 `frontend` 中执行 `npm ci`、`npm run build`。
4. 在项目根目录执行 `python run_web.py`，访问 `http://127.0.0.1:8080`。

Web 无需 QQ 凭据、NapCat 或 Docker。缺少外部服务配置时网页仍可打开，对应能力需要配置后才能调用。当前 Web 使用本机回环地址，不提供多人账号与公网访问入口。

本地向量检索默认关闭，不要求下载模型或安装 `requirements-embedding.txt`；确需启用时按 Web 指南准备可选依赖与本地模型。

## 已有用户升级

1. 停止正在运行的后端，备份自己的 `.env` 和数据目录（Web 默认 `data/web`）。
2. 拉取更新，重新安装 Python 依赖；前端执行 `npm ci`、`npm run build`。
3. 保留自己的 `.env`，不要用模板覆盖已有配置；核对新增的可选配置后启动。
4. SQLite 结构升级在新版服务启动时执行，旧方案草稿在会话访问时分批校验；原编号和正文保留，删除或已采用的方案不会被恢复。

运行数据和密钥由各部署者自己提供。代码同步不包含本地数据库、上传附件、真实配置、实验调用记录或模型文件。

## 验证与源码范围

仓库保留完整业务代码、前端源码及锁文件、配置模板、部署文件、离线测试、静态评测数据和必要的脱离运行环境的回归夹具。回归测试不依赖个人机器上的历史实验报告。

发布验证使用仅含 Git 暂存文件的独立目录，检查部署文件集合能否运行后端测试、离线评测及前端构建。可使用 README 中的开发命令复现；GitHub Actions 继续执行 Windows/Linux 后端与 Linux 前端验证，具体运行结果以对应提交的 CI 记录为准。

搜索覆盖、真实票价、预约政策、酒店价格和外部服务连通性依赖实际数据源，离线测试通过不代表这些信息始终可取得。研究会明确保留未知、冲突与目标日期待确认状态。
