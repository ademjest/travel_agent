日期：2026-09-23

## 修复内容

- 移除列表容器上的 `white-space: pre-line`，避免 ReactMarkdown 标签之间的格式化换行变成可见空行。
- 为列表标题段落、嵌套列表和同级项目设置独立紧凑间距；正文行高从 1.85 调整为 1.72，普通段落下边距从 12px 调整为 9px。
- 新增统一 Markdown 标准化：无论回复从“旅行行程”“已采用方案草稿”还是其他说明开头，已确定日期和日期待定的“第 N 天”都会转换为同级三级标题。
- “住宿候选”“餐饮候选”转换为同级标题；行程创建／修改预览和正式行程标题转换为二级标题。
- 历史普通回答中的独立粗体区块标题转换为二级标题，编号项目中的粗体名称保持在编号同一行。
- `TripService.format_trip()` 在各天、住宿／餐饮候选和地点依据之间输出明确空行，提高 Web Markdown 及 QQ 纯文本的稳定性。
- TravelAgent 输出规范要求主要区块使用 `##`、子区块使用 `###`，编号与标题保持同一行。
