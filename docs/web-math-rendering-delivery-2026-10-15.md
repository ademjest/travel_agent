# Web 对话数学公式渲染

日期：2026-10-15

## 问题与实现

原消息组件仅使用 `react-markdown` 和 `remark-gfm`，会将 LaTeX 命令、分式、上下标作为普通文字显示。Markdown 还会消费 `\[` 等转义字符，单独安装公式渲染器不能覆盖这些写法。

本次在共享 Markdown 组件接入 `remark-math` 和 `rehype-katex`，使用本地 KaTeX 样式及字体；公式正文在浏览器内排版，不需要联网调用公式服务。KaTeX 与插件依赖保持同一版本，避免样式和字体不一致。

支持：

| 格式 | 用途 |
| --- | --- |
| `$E=BLv$` | 行内公式 |
| `\(E=BLv\)` | 兼容 LaTeX 行内定界符 |
| `$$` 包围的多行内容 | 独立公式 |
| `\[...\]` | 兼容 LaTeX 独立公式 |
| 单独一行 `[`，接 LaTeX 正文，再单独一行 `]` | 兼容用户现有回复中的公式块 |

方括号块只在正文具有数学特征时转换，普通说明文字和 Markdown 链接继续按原逻辑显示。代码围栏、未闭合围栏、缩进代码和行内代码会保留原文。常见美元金额如 `$20 和 $30` 会保留为金额，同时支持 `$2 + 2 = 4$` 等数字公式。

公式错误时显示可读的源码作为降级结果，周围文字继续显示。保留 `skipHtml`，禁用 KaTeX 的受信任 HTML/链接命令，并限制宏展开和尺寸。长公式限制在消息宽度内，可横向滚动；输出包含 MathML 便于辅助阅读。

## 用户示例

以下消息中的两段内容均作为独立公式显示，分式、下标和上标均正常排版：

```text
常用关系：
[
E=BLv,\qquad I=\frac{E}{R},\qquad F_A=BIL
]
如果磁场、导体棒和速度方向满足标准垂直关系，则：
[
F_A=\frac{B^2L^2v}{R}
]
因此安培力通常随速度增大而增大。
```

## 改动范围

- `frontend/src/App.tsx`：接入数学解析与渲染插件。
- `frontend/src/mathMarkdown.ts`：公式定界符兼容与代码/金额保护。
- `frontend/src/main.tsx`：加载本地 KaTeX 样式和字体。
- `frontend/src/styles.css`：公式间距、长公式滚动及错误公式样式。
- `frontend/package.json`、`frontend/package-lock.json`：新增并锁定依赖。
- `frontend/src/Markdown.test.tsx`：公式、普通文本、代码、金额及异常输入回归。

只调整展示，聊天记录与复制原文保持原有行为；已有消息刷新后会通过新的共享组件重新渲染。QQ 输出不受本次前端改动影响。
