# 景点官网导航（U1）

2026-10-27 中途修复：官网查询现可独立调用，不要求已有行程、配置高德或先调用问道。可以直接说“湖北省博物馆官网是什么？”；已有研究后可说“继续查询剩余官网”。有多个同名场馆时需补充城市或分馆。仅查官网不需要出行日期。

独立与行程资料共用 `SearchTool.query_official_website`。补查剩余官网会创建新的有界请求；打开旧报告、查看保存资料或仅润色仍不联网。官网发现先于问道资料之后的可选事实补查，多个对象分轮处理，共享原有总额度。

搜索诊断按选定评测批次启用，完整响应保存在本地验证材料；普通运行日志只记录元数据。真实搜索召回、读页失败与身份未确认分别报告，不能从没有链接推断网站不存在。当前工具目录尚未覆盖其余全部业务 owner，迁移状态见 `docs/2026-10-27-tool-standalone-inventory.json`。

新景点研究和新行程的研究资料可以补充官网入口。默认启用；在本地配置中设置 `RESEARCH_OFFICIAL_LINKS_ENABLED=false` 并重启，可停止新发现，已保存的资料与链接不删除。Tavily 仍使用原有 `SEARCH_API_KEY` 和固定官方服务地址。

官网入口是独立导航记录，不是票价、开放时间或预约规则的官方核验结果。新发现不会写入 `data/official_sources.json`，不会扩大 `OfficialSources.verify()`、预约提醒或行程确认的权限。

## 发现与展示

程序先锁定景点、城市和分馆范围，复用当前资料、同会话同所有者的有效导航记录及审核登记；已有机构页面的明确出链优先直接读页。仍缺少时再使用 Tavily。

- 审核登记必须匹配实体、城市、允许路径及页面对象标记。
- 未登记站点必须同时具备匹配的城市/对象/运营主体，以及政府文旅部门或已确认机构页面对“该对象官方网站”的明确出链。当前政府页面识别使用 `.gov.cn` 加明确机构主体；其他未登记页面没有足够独立证据时省略。
- 搜索标题中的“官网”、外观相似的域名、版权或备案号不能独立证明身份。现有旅行平台目录中的 OTA/社区地址不会作为景点官网。
- 同名异地、分馆不匹配、跨域跳转、相互冲突的独立站点、公众号/小程序缺少可核对网页时，不生成猜测地址。

已确认 URL 由程序在写作校验后放入该景点的预约规则。URL 不作为待生成字段交给写作模型。写作失败、已保存回答读取、聊天和报告共用同一导航字段。报告采用显式安全外链，打开报告不会触发搜索。

单独问开放时间等简短问题不因此发起官网发现。明确询问官网时，默认输出槽位使用预约规则入口，不新增“官网事实”类型。免费但需要预约的场馆与票价未知的入场型场馆也可发现官网；不会把人均消费、优惠票或套餐价格作为普通门票收费判断。

## 范围、预算与恢复

“只用问道”“只看高德”“不要联网”“只看已保存资料”和域名限定继续生效；已保存链接也按本次来源范围过滤。单纯润色已保存回答不增加官网查询。找不到链接时保留原有预约文字，不加“官网未找到”占位。

每个对象最多一次初始 Tavily 查询；仅有明确机构出链或匹配运营主体候选时，才允许一次身份补查。官网与原事实研究共享总计 **8 轮逻辑搜索、12 页读取**和现有执行时限，为写作预留时间。这是应用层次数上限，不是供应商底层物理请求数或账单保证。达到时限/额度后保留已找到的入口，其余省略，原因与覆盖数记入研究进度及诊断。

缓存策略版本是 `official-navigation-v1`，最长七天，按证据中最早的实际检查时间计算；展示不会把旧证据重新盖上今天的时间。缓存键包含城市、实体/分馆、来源限制、平台目录和官方登记版本/范围。识别算法改变时应更新策略版本。缓存命中不证明页面上的规则仍适用于旅行日期。

外部搜索提交前保存进度。已完成或提交结果未知的搜索在同事件恢复时不会重复提交；已读页面、重复景点和已确认链接优先复用。部分失败不会把原本可回答的景点研究变成整体失败。

## 离线验证

完整发布门禁仍使用 `python scripts/run_release_checks.py --output 新目录`。U1 固定资料场景已登记到既有评测目录：

```text
python scripts/run_evaluations.py official_navigation --output 结果文件.json
```

该场景只支持离线模式，使用独立临时数据库、固定问道回答、假 Tavily 与假读页，不加载真实服务配置，不发送 QQ 消息。它验证导航成功但事实不升级、来源限定、未确认官网省略及恢复不重查；不代表真实官网识别精度、网络延迟或实际接口费用已经通过测量。
